RAG Assistant
RETRIEVAL-AUGMENTED GENERATION

A LangChain-based RAG chatbot that answers questions grounded entirely in Paul Graham's ~200 published essays, with inline source citations. Chunks essays (~1500 chars, 200-char overlap), embeds them locally with all-MiniLM-L6-v2 (no per-query embedding cost), and retrieves the top-5 relevant chunks from a persistent ChromaDB store before generating an answer with a switchable Claude or Groq backend.

An automation pipeline that discovers currently popular VS Code extensions from live Marketplace install-count data — not a fixed list — scrapes each one's real listing with Playwright, and generates an improved description, category, and keywords through switchable Groq/Gemini backends.
